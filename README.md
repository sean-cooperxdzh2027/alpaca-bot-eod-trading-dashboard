## Overview

Alpaca Bot EOD Dashboard provides a static web UI for reviewing daily results generated by Alpaca-connected trading workflows. Information from Alpaca Live, Alpaca Paper, and Alpaca Crypto can be viewed through a single dashboard rather than across separate reports.

Crypto records are maintained as a distinct historical dataset, while BTC/USD execution activity has its own tracking focus. The interface also presents a strategy based on a 1.5R take-profit target and closing the entire position, supporting both daily performance checks and historical crypto analysis.

- Inspect end-of-day trading figures through a dedicated dashboard
- Choose data from Alpaca Live, Alpaca Paper, or Alpaca Crypto

## Getting Started

### Download the repository

```bash
git clone https://github.com/sean-cooperxdzh2027/alpaca-bot-eod-trading-dashboard.git
cd REPO
```

### Start a local server

This project consists of static HTML content. Run it through any local static web server, such as Python's built-in server:

```bash
python -m http.server 8000
```

Visit the following address after the server starts:

```text
http://localhost:8000
```

### Publish with Vercel

1. Add the repository to Vercel by importing it.
2. Set the project type to a static site.
3. Match the Vercel configuration to the repository's asset structure.
4. Deploy the project and use the resulting Vercel URL to access it.

## Data and Configuration

The dashboard expects Alpaca and crypto metrics to remain organized in source-specific datasets. Keep each dataset consistent with the view that reads it, and provide BTC/USD execution entries whenever pair-level reporting is needed.

The static site can use a configuration structure such as:

```json
{
  "dataSource": "alpaca-paper",
  "symbol": "BTC/USD",
  "takeProfitRiskMultiple": 1.5,
  "closePositionPercent": 100
}
```

When modifying records, follow the data and asset conventions already used by the repository.

## Common Questions

### What environments can run the dashboard?

It is built for the web and can be deployed as a static site through Vercel.

### Which sources does it use?

The dashboard supports Alpaca Live, Alpaca Paper, and Alpaca Crypto, plus a separate dataset containing crypto metric history.

### Is BTC/USD supported?

Yes. The dashboard includes execution tracking for the BTC/USD pair.

### What take-profit model does it show?

Results are based on a 1.5R take-profit strategy where 100% of the position is closed.

### How can I refresh the metrics?

Change the source dataset or records used by the static site, then redeploy the project to publish the updated dashboard content.

### What can cause the dashboard to fail to load?

Check that the deployment is serving files from the intended root. Also confirm that all referenced datasets and assets exist, and review the browser developer console for loading or path errors.

### How do I report a problem?

Create a repository issue and include the deployment context, selected source, affected dashboard view, and any relevant browser console errors.
